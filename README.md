# qa-only

一个用于**只测试、不修复（report-only QA，仅报告式测试）**的 Skill。

## 这个 Skill 是干什么的
它会像真实用户一样测试页面与流程，但**不会修改代码**。

重点在于：
- 发现问题
- 记录证据
- 输出结构化报告
- 给后续修复提供清晰上下文

如果你想保留现场、先看问题全貌，这个 Skill 比 `qa` 更合适。

## 什么时候用
适合这些场景：
- 你只想做验收，不想当场改代码
- 你要把问题交给别人修
- 你想先拿到一版客观报告再决定是否进入 fix loop
- 你想做 diff-aware QA，但先不动实现

## 核心输出
通常会产出：
- QA 报告
- 截图证据
- 复现步骤
- 健康分（health score）与问题分类

## 不适合的场景
它不适合：
- 你希望 Agent 顺手修掉问题
- 你已经知道问题在哪里，只差代码修复

## 相关 Skills
- `qa`：测试后继续修复与复验
- `design-review`：更偏设计质量问题
- `review`：更偏代码结构与 diff 风险
